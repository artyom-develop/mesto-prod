Стартовый набор для выполнения проектной работы Место

Для установки зависимостей выполните:

```bash
npm install
```

Для локального запуска проекта используйте:

```bash
npm run dev
```

Сборка проекта для публикации:

```bash
npm run build
```

Публичный репозиторий для GitHub Pages должен публиковать сборку из ветки `gh-pages`, а исходный код остаётся в основной ветке.
