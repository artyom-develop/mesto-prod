Стартовый набор для выполнения проектной работы Место

Для установки зависимостей выполните:

```bash
npm install
```

Для локального запуска проекта используйте:

```bash
npm run dev
```

Сборка проекта для публикации:

```bash
npm run build
```

Публикация на GitHub Pages выполняется через GitHub Actions и артефакт сборки из папки `dist`.
